# 🏆 The Great Indian AI Internship Challenge — Overview

## What Is This?

Gnani AI (an Indian AI company) is running a **national-level AI internship challenge** where students build real projects using Gnani's own speech and language models. The best builders get paid internships, stipends, and awards.

---

## Quick Summary

| Reward | Details |
|--------|---------|
| **Paid Internships** | Up to **100** six-month internships |
| **Stipend** | Up to **₹1 lakh/month** per intern |
| **Awards** | 10 awards of **₹50,000 each** (₹5 lakh total) |
| **Deadline** | **November 10, 2026**, 11:59 PM IST |
| **Build Credits** | **5,000 free API credits** per registration |
| **API Keys** | **3 free keys** available on the platform |

> [!IMPORTANT]
> You have **~17 days** left (as of Oct 24, 2026). The deadline is **fixed** — no extensions.

---

## What You Get as a Registrant

| Resource | Details |
|----------|---------|
| **Programme Credits** | 5,000 credits to use on the API Platform |
| **API Dashboard** | Test transcription, voices, languages, and create API keys at [app.gnani.ai](https://app.gnani.ai) |
| **Documentation** | API Docs with quick start guides |
| **Models Available** | Prisma (STT), Timbre (TTS, beta), Evon (30B reasoning model) |
| **Support** | Gnani AI team on Discord and email |

---

## The Brief

- **Open brief** — there is NO fixed problem statement
- Build **any app, workflow, or solution**
- The **only requirement** is that you use at least one Gnani AI model/API
- Build **solo** or in a **team of two** (maximum)

## Stipend & Offer Details

- Stipends of up to **₹1 lakh per month** are paid to **each intern individually** — not split across a team
- Offers are **individual** — one teammate can receive an offer without the other
- Only a **written offer from Gnani AI** after the interview stage confirms an internship
- Gnani AI reserves the right to modify, suspend, or cancel any part of this contest at its sole discretion
